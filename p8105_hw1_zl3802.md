# Problem 1

``` r
library(ggplot2)

data("penguins", package = "palmerpenguins")
```

The `penguins` dataset has information about penguins, such as species,
island, bill length, flipper length, body mass, sex, and year. The
species are Adelie, Chinstrap, Gentoo. The islands are Biscoe, Dream,
Torgersen. There are 344 rows and 8 columns. The mean flipper length is
200.92 mm.

``` r
flipper_bill_plot =
  ggplot(
    penguins,
    aes(
      x = bill_length_mm,
      y = flipper_length_mm,
      color = species
    )
  ) +
  geom_point()

flipper_bill_plot
```
